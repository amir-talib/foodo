# Foodo - Restaurant Technology Platform

This project is a clone of [Tarro.com](https://www.tarro.com) with rebranding to "Foodo" and a customized color scheme.

## Features

- Modern UI built with Next.js and shadcn/ui components
- Responsive design that works on mobile, tablet, and desktop
- Custom brand colors:
  - Primary: #38826E (a teal green)
  - Secondary: #FF6B00 (orange)
- Custom fonts (Deacon and Questrial)
- Interactive navigation and dropdown menus
- Testimonial carousel

## Technologies Used

- [Next.js](https://nextjs.org/) - React framework
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [shadcn/ui](https://ui.shadcn.com/) - Component library
- [React Icons](https://react-icons.github.io/react-icons/) - Icon library
- [Embla Carousel](https://www.embla-carousel.com/) - Carousel component

## Development

To run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
